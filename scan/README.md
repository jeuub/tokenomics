# tokenomics-scan — «посмотри свою реальную экономию» в одну команду

Self-serve инструмент: читает **локальные** логи Claude Code (и, позже, opencode), считает реальный профиль
использования и выводимую оценку экономии Tokenomics. **Ничего не загружается в сеть** — весь расчёт на машине
пользователя. Это и есть честная замена «красивым числам из ниоткуда» на сайте: пользователь видит свою цифру.

## Запуск

Сейчас (без публикации):
```bash
node scan/tokenomics-scan.mjs            # последние 30 дней
node scan/tokenomics-scan.mjs --days=7   # другой период
```

Целевая дистрибуция (лёгкий доступ для пользователя — одна строка, как ccusage):
```bash
npx tokenomics-scan          # после публикации в npm
# или
curl -fsSL https://get.tokenomics.dev/scan | sh
```

## Что показывает (всё за период)
- **Факт из логов:** ходов, средний контекст/ход, дефолт-модель, **реальный расход $** (твои токены ×
  выверенные прайс-листы — это факт, не оценка).
- **Оценка с Tokenomics:** смешанная экономия % и «было → стало», выведенная из ТВОЕГО профиля
  (распределение задач, cheapest-sufficient среди провайдеров). Иллюстративно; допущения печатаются.

## Принципы (совпадают с [../docs/honest-numbers.md](../docs/honest-numbers.md))
- Ход уводим **только когда он реально дешевле** — иначе он остаётся на твоей модели; **никогда не делаем
  дороже дефолта** (поэтому при огромном кэшированном контексте часть ходов «kept», и экономия честно ниже).
- Реалистичный мікс: рутину забирают дешёвые сторонние/free (DeepSeek/GLM/Qwen/Gemini-free), Anthropic — на
  трудных/закреплённых. Никакого выдуманного %; реальное число замеряется на трафике после подключения.

## Privacy
Открываются только метаданные `usage` и имя модели из JSONL; **тексты переписок не читаются и никуда не
передаются**. Для self-host/закрытых сред это критично — инструмент работает офлайн.

## Привязка к сайту
Секция-оценщик на лендинге даёт кнопку/строку «посмотреть свою реальную цифру» = эта команда. Пользователь
запускает локально, видит свой расход и оценку, и (опционально) вводит свои числа в оценщик на сайте —
вместо иллюстративных. Никакой загрузки данных к нам.
